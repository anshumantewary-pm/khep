# Khep

A clickable prototype of a freight app for Indian road transport. Every load on Khep is paid for before it is posted: the shipper funds escrow, the truck owner gets 90% by UPI at loading and the rest on delivery proof, and the driver uses the app in Hindi or English.

The prototype has three views:

- **Shipper:** post a load with a fair price range for the lane, pick a verified truck, track the trip and its documents.
- **Truck owner:** see only paid-for loads, book a return load before the truck arrives, see payments, fuel credit and document expiry dates.
- **Driver:** five big steps per trip, automatic waiting-time billing, expenses and rest stops.

Below the phone, the page sets out the revenue model, the rollout plan and the assumptions to test.

All names, vehicles and figures are illustrative examples.

## Run it

Open `index.html` in a browser. It is a single static file with no build step.
